### defect 1: pnpm-lock.yaml out of sync

**classification**: repo quirk

**rationale**: this was user error, not a practice defect. tsx was moved to dependencies but `pnpm install` was not run before commit. the practice correctly requires lockfile sync — the user (prior session) failed to run install.

**evidence**: the declapract practice does not control when users run `pnpm install`. it only validates that lockfile is in sync on CI.

**action**: none. this is not a practice bug to report.

### defect 2: keyrack firewall fails on extended keyrack not found

**classification**: practice bug

**rationale**: the keyrack.yml created by declapract-typescript-ehmpathy extends dispatcher keyrack.yml, but prepare:rhachet does not include dispatcher in the roles list.

**evidence**:
- keyrack.yml extends `.agent/repo=bhuild/role=dispatcher/keyrack.yml`
- prepare:rhachet (from practices) does not include dispatcher role
- this causes keyrack firewall to fail with "extended keyrack not found"

**root cause**: declapract-typescript-ehmpathy creates keyrack.yml that extends dispatcher, but does not ensure dispatcher is in the prepare:rhachet roles list.

**action**: report to declapract-typescript-ehmpathy
