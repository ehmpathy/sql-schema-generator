## CICD defects

### defect 1: pnpm-lock.yaml out of sync

**what**: CI failed with `pnpm-lock.yaml is not up to date with package.json`

**how**: package.json has tsx in dependencies, but lockfile had tsx only in devDependencies
```
"dependencies" in the lockfile (...,"zod":"4.3.4"}) doesn't match package.json (...,"tsx":"4.20.6",...,"zod":"4.3.4"})
```

**why**: when tsx was moved from devDependencies to dependencies (for commander CLI runtime), `pnpm install` was not run before the initial commit

**fix**: ran `pnpm install` to regenerate lockfile with tsx in dependencies section, committed and pushed

**status**: fixed

### defect 2: keyrack firewall fails on extended keyrack not found

**what**: CI jobs `test-shards-integration` and `test-shards-acceptance` fail with:
```
BadRequestError: extended keyrack not found
{
  "path": ".agent/repo=bhuild/role=dispatcher/keyrack.yml"
}
```

**how**: keyrack.yml extends dispatcher keyrack.yml, but dispatcher role was not in prepare:rhachet roles list

**why**: keyrack.yml (created by declapract upgrade) extends three role keyracks:
```yaml
extends:
  - .agent/repo=bhrain/role=reviewer/keyrack.yml
  - .agent/repo=bhuild/role=dispatcher/keyrack.yml
  - .agent/repo=ehmpathy/role=mechanic/keyrack.yml
```

but the prepare:rhachet command only initialized these roles:
```
rhachet init --roles mechanic behaver driver reviewer librarian ergonomist architect
```

note: `dispatcher` is missing. so the symlink to dispatcher keyrack.yml was never created, causing keyrack firewall to fail.

**fix**: added `dispatcher` to the prepare:rhachet roles list:
```
rhachet init --roles mechanic behaver driver dispatcher reviewer librarian ergonomist architect
```

**status**: fixed
